# Чернетка рекомендації L10 · пілот на 12 кейсах

## 1. Рішення

Зберегти хмарного суддю як чинну конфігурацію з ручною перевіркою. Локального кандидата поки використовувати для калібрування, зокрема для перевірки помилок на очевидних PASS. Пілот дав 7/12 узгоджених кейсів проти 10/12 у хмарного судді. За правилом Wilson їх не відрізнити на цьому обсязі. Рішення для ДЗ потребує повного калібрування.

## 2. Периметр

Пілот передавав записані відповіді й рубрику з Docker на Ollama цього комп'ютера. Запитів до PayPilot-агента не було. Перед перенесенням релізного гейта окремо перевірити, куди йдуть запити агента, траси, журнали й збережені матеріали.

## 3. Контракт

Перевірено 7 листопада 2026 року: `qwen2.5:7b` (Q4_K_M), 4 683 087 332 байти, Ollama 0.40.15, temperature 0, один послідовний виклик, `format=schema`. Повний дайджест є в [конфігурації](../judge.local.env). На однокейсовій перевірці обидва режими дали 3/3 валідних JSON-об'єктів і дослівних цитат. На пілоті 60/60 відповідей були JSON-об'єктами, 10/60 стали MISS через недослівну цитату.

## 4. Дві заяви поруч

| На однакових 12 кейсах | Хмарний Haiku 4.5 | Локальний Qwen 2.5 |
| --- | ---: | ---: |
| Узгодженість | 10/12 (83,3%) | 7/12 (58,3%) |
| 95% Wilson | 55,2–95,3% | 32,0–80,7% |
| Півширина інтервалу | ±20,1 п.п. | ±24,4 п.п. |
| Самоузгодженість | 11/12 | 10/12 |
| Очевидні PASS | 4/4 | 1/4 |
| Очевидні FAIL | 4/4 | 4/4 |
| Спірні | 2/4 | 2/4 |

Інтервали перекриваються. На спірній третині обидва мають Wilson 15,0–85,0%, але погоджуються з людиною на різних кейсах. Локально серед очевидних PASS було дві серії без валідної більшості та одна хибна тривога. У спірній третині були ще дві хибні тривоги. Хмарний суддя дав дві хибні тривоги на спірних кейсах.

**Де не працює локальний суддя.** На формулюваннях про передачу справи людині він може відхилити пропозицію або непрямий опис передачі. Навіть коли він приймає явну передачу, він іноді підставляє шаблонну цитату замість слів із відповіді. Обидві такі серії зіпсували всі п'ять спроб.

## 5. Ціна у двох валютах

60 послідовних викликів зайняли 19 хв 46 с. `t_local = 1 186,27 / 60 = 19,77 с`, медіана окремого запиту 14,25 с. Для прогнозу використано середнє повного прогону, що включає обробку першого виклику нових кейсів.

| Сценарій | Локальна оплата за токени | Прогноз часу локального судді |
| --- | ---: | ---: |
| Калібрування ДЗ9, 150 викликів | 0 | ≈49 хв 26 с |
| Поточний релізний runner, один вердикт на кожен із 5 judge-кейсів | 0 | ≈1 хв 39 с |
| Варіант із суддею на кожному із 5 повторів, 25 викликів | 0 | ≈8 хв 14 с |

Час стосується судді. Оцінка ДЗ8 для перших 150 хмарних спроб — USD 0,182620. Локальний запуск використовує час CPU й електроенергію.

## 6. Обмін і умови

Зберегти ручну перевірку всіх вердиктів ескалації. За мандату Zero regulatory risk застосовувати локальний результат як допоміжний сигнал після незалежної перевірки на відповідному наборі. Окремо фіксувати версію моделі, режим виклику та шлях решти даних за межами судді.

## 7. Конфігурація й перекалібрування

Використано [judge.local.env](../judge.local.env) та `schema`. Перекалібрувати після зміни тегу або дайджесту, runtime, температури, формату, режиму виклику, рубрики, домену або промпту агента.

Прогноз перед пілотом був 9/12, отримано 7/12. Спірні формулювання справді дали промахи, а очевидні PASS стали більшою проблемою, ніж очікували. Середні 19,77 с увійшли в попередній діапазон 15–45 с.
